# MyPass – Password Manager

A simple desktop **Password Manager** built with **Python and Tkinter**.

This app lets you:
- Generate strong random passwords.
- Save website, email/username, and password details.
- Store credentials locally in a text file.
- Quickly copy and reuse passwords.

## Built With
- Python
- Tkinter (GUI)

## Features
- Random password generator.
- Saves all webiste data in a .json file.
- Webiste credentials can be retrieved using a "search" button.
- Confirmation popup before saving.
- Automatically clears input fields after saving.
